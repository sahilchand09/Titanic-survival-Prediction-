# Titanic Survival Prediction

## 📌 About
Predict passenger survival on the Titanic using machine learning. Covers data preprocessing, feature engineering, and model evaluation.

## 📊 Dataset
Kaggle Titanic Dataset  
Features: `PassengerId, Survived, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, Embarked`

## 🛠️ Models Used
- Logistic Regression
- Random Forest Classifier
- Decision Tree Classifier

## 📈 Results
Best Model: Random Forest  
Accuracy: 80% 

## 🚀 How to Run
1. `pip install -r requirements.txt`
2. Open `titanic-survival-logistic-regression.ipynb` in Jupyter
3. Run all cells

## 📌 Key Insights
- Women and children had higher survival rate
- Passenger class and fare were important factors
